 Описание
-------------
**Тестовое задание "Учет сотрудников" для участия в образовательном проекте компании Ареал.**


🛠 Технологии
-------------

*   **Backend:** PHP 8.5
    
*   **База данных:** MySQL 9.6.0
    
*   **Frontend:** HTML5, CSS3, Bootstrap 5
    
*   **Контейнеризация:** Docker, Docker Compose
    
*   **JavaScript:** Bootstrap JS, jQuery, jQuery Mask Plugin
    

📦 Установка и запуск
---------------------

### Предварительные требования

*   Docker и Docker Compose
    
*   Git
    

### Шаги по установке

**1\. Клонировать репозиторий**
    
`   git clone   `  

`   cd areal-tz   `

**2\. Запуск Docker контейнеров**

`   docker-compose up -d   `

**3\. Инициализация базы данных**

Скрипты из `database/scripts` выполнятся автоматически при первом запуске и создадут таблицу employees с тестовыми данными.

**4\. Доступ к приложению**

Откройте браузер и перейдите по адресу:

`   http://localhost:80   `
